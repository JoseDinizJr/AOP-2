SITE AOP2 — PREÇOS DE COMBUSTÍVEIS

Como usar:
1. Extraia o arquivo ZIP.
2. Abra index.html no navegador.
3. Os gráficos e a tabela serão exibidos.

O site usa os 20 registros atualmente definidos no projeto físico.
Para cumprir a exigência de 5 coletas em datas diferentes, adicione os
demais registros em js/dados.js no mesmo formato.

Os gráficos incluídos são:
- Preço médio por combustível;
- Preço médio por posto.

A biblioteca Chart.js é carregada pelo navegador a partir de uma CDN,
portanto é necessário estar conectado à internet ao abrir o site.
